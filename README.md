# Nova releases

Installers and auto-update files for **Nova**, a personal AI desktop agent for Windows. This repo holds no source code.

- **Nova**: release `zone-prod`
- **Nova UAT**: release `zone-uat` (testing)
- **Nova Dev**: release `zone-dev` (development builds)

An installed Nova updates itself from its own release. Download the `Nova-<zone>-Setup-<version>.exe` from the release you want.
